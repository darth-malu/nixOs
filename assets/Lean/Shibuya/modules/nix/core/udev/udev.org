** UDEV
ACTION=="add" "remove"
KERNEL=="sd[f-h][0-9]
ENV{ID_FS_UUID}=="uid"
RUN+="/path/to/program/to/execute --flags

When a kernel driver initializes a device, the default state of the device node is to be owned by root:root, with permissions 600.

*** ways to id hard disks
#+begin_src sh
udevadm info /dev/sdX # look for ID_SERIAL_SHORT to ENV{ID_SERIAL_SHORT}
#+end_src
