* play playlists
- use =--playlist=<filename>= - supports common formats
- use =--playlist-start=<auto|index>= to set file to play in internal playlist
  - *index* is an int
  - 0 - first file
  - behavior undefined and may change if:
    - index does not exist
    - if playlist has further playlists
** text file requirements
- files delimited by new line

* interesting flags
+ =--list-options=
+ =--list--properties=
+ =--no-config=
+ =--idle= - Makes mpv wait idly instead of quitting when there is no file to play. Mostly useful in input mode, where mpv can be controlled through input commands
