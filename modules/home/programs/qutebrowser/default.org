* cheatsheet

|----------+---------------------------------------|
| key      | does                                  |
|----------+---------------------------------------|
| gt       | open list of tabs to fuzzy search and |
| +SHIFT+t | go to tab at N                        |
| gD       | move current tab to new window        |
| d        | close current tab                     |
| co       | close all tabs but current            |
| cd       | clear download list                   |
| tsu      | reload                                |
| gi       | go to primary input textbox           |
| ;t       | hints for selecting input textbox     |
|----------+---------------------------------------|
